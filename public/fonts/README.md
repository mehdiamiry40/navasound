# NavaSound share-image font

`Fraunces-Share-Regular.ttf` is an official Google Fonts TrueType subset of
Fraunces, regular weight 400, optical size 72. It contains the characters used in
the share-image headline. Update this subset if that headline introduces new
characters.

Source stylesheet:
https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@72,400&text=Release%20prep%20for%20artists.%20Built%20around%20your%20music.

Upstream project: https://github.com/google/fonts/tree/main/ofl/fraunces

`Geist-Share-Regular.ttf` is an official Google Fonts TrueType subset of Geist,
regular weight 400, for the supporting share-image text. Its source stylesheet
uses `https://fonts.googleapis.com/css2?family=Geist:wght@400` and a `text`
parameter containing the image's supporting copy.

Upstream project: https://github.com/google/fonts/tree/main/ofl/geist

The SIL Open Font Licenses are included in `Fraunces-OFL.txt` and `Geist-OFL.txt`.
